## 🎯 Концепция и возможности

**LevelUp** превращает взаимодействие с Telegram-ботом в захватывающий процесс развития персонажа:
- 📈 **Прозрачный прогресс**: каждые 100 XP повышают уровень персонажа.
- 🎁 **Ежедневный стимул**: ежедневный сбор наград с контролем кулдауна по UTC и выводом по времени `Asia/Tashkent`.
- ⚔️ **Квесты и активность**: ежедневные и еженедельные задания с проверкой реального выполнения на стороне сервера.
- 🏆 **Соревновательный дух**: глобальный рейтинг за все время, а также лидерборды за последние 7 и 30 дней.
- 👥 **Виральный рост**: реферальные deep-link ссылки с защитой от накруток и мгновенным бонусом +50 XP.
- 🛡 **Серверный контроль**: защищенная админ-панель с аудитом операций, управлением квестами и рассылкой.

Интерфейс спроектирован по стандартам премиального темного UI:

- **Прогресс-бары**: кастомные индикаторы `[▰▰▰▰▱▱▱▱▱▱] 40%`.
- **Эргономика кнопок**: лаконичные подписи, постоянная нижняя клавиатура и контекстные inline-кнопки навигации с кнопками «Назад» и «В главное меню».

## 🗄 Схема базы данных и миграции

Миграции запускаются **автоматически** при старте приложения через `app.database.apply_migrations`. Ручное выполнение SQL-скриптов не требуется.

### Основные таблицы:
1. `users`:
   - `id`, `telegram_id` (UNIQUE), `username`, `first_name`, `xp`, `level`, `referral_code` (UNIQUE), `referred_by`, `selected_title`, `selected_badge`, `created_at`, `last_active_at`.
2. `xp_events`:
   - Журнал всех изменений баланса: `id`, `user_id`, `amount`, `reason`, `created_at`, `idempotency_key` (UNIQUE). Гарантирует защиту от повторных начислений!
3. `daily_claims`:
   - `id`, `user_id`, `claim_date` (DATE UTC), `xp_amount`, `created_at`. Уникальное ограничение `(user_id, claim_date)` физически предотвращает повторный сбор за текущие сутки.
4. `tasks`:
   - `id`, `title`, `description`, `category` (`daily`/`weekly`), `reward_xp`, `condition_type`, `condition_target`, `expires_at`, `is_active`, `created_at`.
5. `user_tasks`:
   - `id`, `user_id`, `task_id`, `status`, `completed_at`, `rewarded_at`. Уникальное ограничение `(user_id, task_id)`.
6. `achievements`:
   - `id`, `code` (UNIQUE), `title`, `description`, `icon`, `xp_requirement`, `condition_type`, `condition_value`, `reward_xp`.
7. `user_achievements`:
   - `id`, `user_id`, `achievement_id`, `unlocked_at`. Уникальное ограничение `(user_id, achievement_id)`.
8. `referrals`:
   - `id`, `inviter_id`, `invited_id` (UNIQUE), `created_at`, `rewarded`.
9. `schema_migrations`:
   - Контроль применённых версий миграций.

## 🎮 Игровые механики

### 1. Регистрация и реферальная программа
- При старте `/start` аккаунт создаётся мгновенно без зависаний.
- Генерируется уникальный 8-значный hex-код (например, `A8F1C32D`).
- Поддержка ссылок вида `t.me/<bot>?start=REF_CODE`.
- Защита от **самоприглашения** и повторного учета реферала.
- При успешной регистрации пригласившему начисляется **+50 XP** и отправляется уведомление.

### 2. Профиль игрока и кастомизация
- Отображает текущий уровень, точный опыт `XP: 45 / 100`, визуальный бар `[▰▰▰▰▱▱▱▱▱▱] 45%`.
- Полная статистика: общий XP, ранг в таблице лидеров, выполненные задания, достижения, рефералы.
- Раздел «Кастомизация»: возможность выбрать один из значков (⚡, 🔥, 💎, 👑) и титулов («Новичок», «Исследователь», «Активист», «Кибер-мастер»).

### 3. Система опыта (XP) и уровней
- Формула уровня: `LEVEL = (XP // 100) + 1`.
- Отрицательный баланс невозможен (защита `CHECK (xp >= 0)` в PostgreSQL и `max(0, ...)` в Python-сервисе).
- При получении достаточного опыта бот автоматически отправляет поздравление с повышением уровня.
- Каждое действие сопровождается `idempotency_key`.

### 4. Ежедневный бонус (Daily Reward)
- Фиксированная награда: **+20 XP**.
- Расчет суток ведется строго по **UTC**, обеспечивая единый стандарт без рассинхронизации.
- Интерфейс выводит статус и время перезарядки в часовом поясе **Asia/Tashkent**.
- Если награда уже забрана, при нажатии всплывает Alert с точным обратным таймером до следующей возможности.

### 5. Задания (Daily & Weekly Tasks)
- Разделение по вкладкам **DAILY** и **WEEKLY**.
- Реальная проверка условий на сервере:
  - `daily_claim`: проверяет, забрал ли пользователь ежедневный бонус.
  - `profile_check`: просмотр карточки персонажа.
  - `invite_friend`: проверяет количество приглашенных друзей через репозиторий.
  - `reach_level`: проверяет текущий уровень игрока.
- Защита от повторного клейма наград.

### 6. Рейтинговая таблица (Leaderboard)
- Три режима отображения:
  1. **GLOBAL TOP**: за всю историю по общему XP.
  2. **WEEKLY TOP**: по опыту, заработанному за последние 7 дней (через `xp_events`).
  3. **MONTHLY TOP**: по опыту за последние 30 дней.
- Выделение медалями топ-3: 🥇, 🥈, 🥉.
- **Персональный статус**: внизу таблицы каждый игрок видит собственное текущее место и набранные баллы, даже если он не входит в топ-10!

### 7. Достижения (Achievements)
- Включает достижения:
  - 🚀 **First Step** — первая регистрация в боте (+10 XP).
  - 🔥 **Active User** — 7 дней ежедневных наград (+50 XP).
  - ⚡ **Experienced** — накопить суммарно 1000 XP (+100 XP).
  - ⭐ **Rising Star** — достичь 10 уровня (+150 XP).
  - 👥 **Social** — пригласить 5 друзей (+100 XP).
  - 🎯 **Task Hunter** — выполнить 10 любых заданий (+80 XP).
- Проверяются реактивно в фоновом режиме без задержек для пользователя.

### 8. Виртуальные награды (Rewards)
- Каталог значков и титулов с описанием условий их разблокировки.
- Никаких скрытых платежей, лутбоксов или элементов азартных игр — всё зарабатывается исключительно активностью в боте.

### 9. Админ-панель
- Защищена серверной проверкой Telegram ID по списку `ADMIN_IDS`.
- Доступна по команде `/admin` или специальной кнопке в меню для админов.
- **Функционал**:
  - Сводная статистика (пользователи, прирост за день, активность за неделю, суммарный XP).
  - Поиск игрока по Telegram ID с детальной выгрузкой профиля.
  - Начисление и списание XP с обязательным указанием причины в аудит-лог.
  - Управление квестами (создание через пошаговый FSM-диалог, активация, деактивация, удаление).
  - Массовая рассылка объявлений всем пользователям с отчетом об успешных и неудачных отправках.
  - Просмотр последних 10 записей журнала аудита XP.

## 🚀 Развёртывание на Railway (GitHub → Railway)

Проект изначально оптимизирован под автоматический деплой на **Railway**.

### Шаг 1: Подготовка репозитория на GitHub
1. Создайте новый репозиторий на GitHub (например, `levelup-telegram-bot`).
2. Скопируйте файлы проекта в репозиторий и сделайте push:
   ```bash
   git init
   git add .
   git commit -m "feat: initial LevelUp bot release"
   git branch -M main
   git remote add origin https://github.com/<your-username>/levelup-telegram-bot.git
   git push -u origin main
   ```

### Шаг 2: Создание проекта в Railway
1. Войдите в свой аккаунт на [Railway.com](https://railway.com/).
2. Нажмите **New Project** → выберите **Deploy from GitHub repo**.
3. Выберите репозиторий `levelup-telegram-bot`.

### Шаг 3: Добавление базы данных PostgreSQL
1. В панели проекта Railway нажмите **Create** (или клавишу `Cmd/Ctrl + K`) → выберите **Database** → **Add PostgreSQL**.
2. Railway автоматически свяжет базу данных и предоставит внутреннюю переменную `DATABASE_URL`.

### Шаг 4: Настройка переменных окружения (Variables)
В настройках сервиса бота в Railway перейдите во вкладку **Variables** и задайте:

| Переменная | Обязательно | Описание | Пример значения |
|---|---|---|---|
| `BOT_TOKEN` | **Да** | Токен бота от @BotFather | `7123456789:AAH...` |
| `DATABASE_URL` | **Да** | Подключение к PostgreSQL | `${{Postgres.DATABASE_URL}}` (ставится автоматически) |
| `BASE_URL` | **Да** | Публичный HTTPS-домен сервиса | `https://levelup-production.up.railway.app` |
| `WEBHOOK_SECRET` | **Да** | Секретная строка для проверки заголовка Telegram | `3f8a9e2b1c4d5e6f7a8b9c0d1e2f3a4b` |
| `ADMIN_IDS` | **Да** | Telegram ID администраторов через запятую | `123456789,987654321` |
| `PORT` | Авто | Порт сервиса | Railway назначает `$PORT` автоматически |
| `TIMEZONE` | Нет | Часовой пояс для отображения | `Asia/Tashkent` |
| `USE_POLLING` | Нет | Режим Polling (только для локальной отладки) | `False` |

> 💡 **Как узнать публичный домен `BASE_URL` в Railway?**  
> В панели сервиса перейдите в **Settings** → раздел **Networking** → нажмите **Generate Domain**. Скопируйте полученный адрес вида `https://xxxx.up.railway.app` в переменную `BASE_URL`.

### Шаг 5: Проверка запуска
1. Railway запустит сборку через `railway.json` / `Procfile`.
2. При старте выполнится автоматическая миграция `migrations/001_initial_schema.sql`.
3. Бот зарегистрирует Telegram Webhook по адресу `https://xxxx.up.railway.app/webhook` с секретным токеном `WEBHOOK_SECRET`.
4. Для проверки доступности перейдите в браузере по адресу:  
   `https://xxxx.up.railway.app/health`  
   Ответ: `{"status": "ok", "service": "LevelUp Telegram Bot", "version": "1.0.0", "mode": "webhook"}`.
5. Откройте бота в Telegram и отправьте `/start`!

## 💻 Локальный запуск и разработка

Если вы хотите запустить и дорабатывать бота локально на своём компьютере:

### 1. Клонирование и установка зависимостей
```bash
python -m venv .venv
# Активация окружения:
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Настройка `.env`
Создайте файл `.env` на основе шаблона:
```bash
cp .env.example .env
```
Укажите актуальный `BOT_TOKEN`, параметры подключения к локальному PostgreSQL и свой Telegram ID в `ADMIN_IDS`.

### 3. Режим локального опроса (Polling)
Для локальной разработки без проброса портов и SSL установите в `.env`:
```ini
USE_POLLING=True
```
И запустите приложение:
```bash
python -m app.main
```
Бот автоматически снимет активный вебхук и перейдет в режим `getUpdates`.

## 🔒 Безопасность и отказоустойчивость

- **Никаких секретов в коде**: все токены, ключи и пароли передаются исключительно через переменные окружения.
- **Проверка подлинности вебхука**: каждый запрос от Telegram валидируется заголовком `X-Telegram-Bot-Api-Secret-Token` против значения `WEBHOOK_SECRET`.
- **Защита от дубликатов (Idempotency)**: все начисления опыта сопровождаются уникальным ключом `idempotency_key` в таблице `xp_events`. Повторное нажатие или повторная доставка вебхука никогда не приведут к двойному начислению опыта!
- **Транзакционность (ACID)**: обновление уровня и баланса пользователя выполняется в единой транзакции с блокировкой строки `FOR UPDATE`.
- **Server-Side Authorization**: все административные функции в роутере `admin.py` проверяют права вызывающего пользователя перед выполнением операции.
- **Graceful Shutdown**: при остановке контейнера корректно закрываются сессия aiogram HTTP-клиента и пул соединений asyncpg.
